# Серверная админка ProfiSport Electro

Требования: PHP 8.1+, PDO SQLite, HTTPS. База хранится на том же сервере, что и сайт; для российского размещения нужен сервер в России. GitHub Pages исполнять PHP не умеет.

1. Разместите содержимое dist в публичной директории сайта. Папка server должна находиться рядом с публичной директорией, вне доступа через HTTP: public/api/admin.php обращается к ../../server/bootstrap.php.
2. Создайте приватную директорию данных вне публичной директории с правом записи для PHP.
3. Скопируйте server/config.example.php в server/config.php. Укажите абсолютный путь к приватной директории и логин сотрудника.
4. Получите хеш выбранного пароля с помощью password_hash(..., PASSWORD_DEFAULT) в PHP и запишите только хеш в admin_password_hash. Пароль и config.php не добавляйте в GitHub.
5. Откройте /admin/ и войдите. Начальный каталог будет импортирован один раз. Дальнейшее редактирование сохраняется в electro.sqlite и сразу используется витриной через /api/catalog.php.

Товары с неуточнёнными названиями находятся в черновиках. Чтобы опубликовать товар, уточните модель и выберите раздел. Цена без значения показывается как «По запросу».

Для резервной копии сохраняйте базу electro.sqlite и config.php вне публичной директории. Не заменяйте базу при обновлении файлов сайта. Повторная загрузка seed не затирает изменения сотрудника.

Проверки: python3 tests/admin-smoke.py на машине с PHP. Тест использует отдельную временную базу и не меняет рабочие товары.
