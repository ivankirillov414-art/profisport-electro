# ProfiSport — электротранспорт

[Открыть сайт](https://profisport-electro.cty2m4vt2j.chatgpt.site) · [Каталог](https://profisport-electro.cty2m4vt2j.chatgpt.site/catalog.html) · [Панель выбора](https://profisport-electro.cty2m4vt2j.chatgpt.site/panel.html)

Текущая публикация сохраняет доступ владельца через ChatGPT. GitHub содержит исходники.

## Возможности

17 моделей, поиск и фильтры, сравнение до трёх моделей, карточки с источниками и датами проверки, сохранение подбора. Главная: три студийных слайда с переходами к конкретной модели. Студийные иллюстрации не заменяют оригинальные фотографии в каталоге.

Запрос магазину открывает письмо на profisport56@yandex.ru: клиент отправляет его в своём почтовом приложении. Серверная отправка и приём заявок пока не настроены. Контакты сверены с https://velo56.ru/kontakty/.

3D и 360 исключены по решению владельца. Архивные исходники моделей сохранены; интерфейс и сборка их не используют.

## Ограничения проверки

Изменения 06.10.2026 проверяются статически и функционально. Живое сравнение desktop/mobile с референсами пока не выполнено из-за отсутствия разрешённого браузерного инструмента. До него визуальная готовность не подтверждается.

Остальные цены и параметры проверены 05.10.2026, V3 и G3 Pro — 06.10.2026. Цена и наличие у поставщика не означают цену или склад ProfiSport. Доставка требует расчёта.

Для запуска: `python -m http.server 8000 --directory dist` (на своём компьютере).

До коммерческого запуска нужны реквизиты продавца, собственные документы обработки данных, согласованные условия гарантии электротранспорта и канал серверного приёма заявок.

## Обновление 07.10.2026

Исправлено смещение фото в панели: старые абсолютные координаты больше не сдвигают изображение за границы. Каталог использует единые вертикальные карточки с выровненными ценами; на узких телефонах — одна колонка. Убрано двукратное увеличение фотографий в категориях. Текущий мобильный шоурум сохранён. 3D/360 не включаются. Визуальная проверка desktop/mobile остаётся незавершённой.

## Обновление 19 — карточки категорий

Категории получили прозрачные вырезки G2 Max, C1 Pro и WISH 01, подготовленные встроенным инструментом изображений по фотографиям поставщика. Вырезки используются только в оформлении главной; каталог и панель сохраняют исходные фотографии. Карточки на телефоне уменьшены до 142 px, масштаб техники увеличен за счёт удаления полей исходного фото. Мобильный слайд WISH 01 использует отдельную вырезку поверх пустого шоурума без растяжения пропорций. Визуальная проверка в браузере недоступна.

Промпт для каждого ассета: background-extraction; удалить светло-серый фон и пустые поля, сохранить технику целиком, исходную геометрию, цвета и логотип; прозрачный фон, без пола и отражения.
