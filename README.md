# ProfiSport — электротранспорт

Отдельный сайт и клиентская панель выбора техники.

## Запуск

Из корня проекта: `python -m http.server 8000 --directory dist`

Главная: http://localhost:8000/
Панель: http://localhost:8000/panel.html

## Файлы

- `dist/index.html` — главная и каталог.
- `dist/panel.html` — клиентская панель.
- `dist/style.css` — оформление и мобильная версия.
- `dist/app.js` — фильтры, сравнение и выбор модели.
- `dist/catalog.js` — модели, характеристики, цены и ссылки на поставщиков.
- `dist/assets/` — изображения.

Данные проверены 05.10.2026. Цены поставщиков — ориентиры. Цена ProfiSport, наличие и сроки доставки подтверждаются отдельно. Заказы и платежи не отправляются.
